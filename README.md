# 🏃‍♂️ BlackRun - Experimental

> Um jogo de corrida infinita minimalista estilo *Xiao Xiao* desenvolvido em HTML5 Canvas e JavaScript puro.

🎮 **[CLIQUE AQUI PARA JOGAR AO VIVO](https://jeffersoongomes.github.io/BlackRun/)**

---

## 📌 Sobre o Projeto
O **BlackRun** é um projeto experimental focado em conceitos fundamentais de desenvolvimento web e programação de jogos 2D no navegador:
* **HTML5 Canvas:** Renderização gráfica e animação frame-a-frame de personagens stickman.
* **JavaScript Puro (ES6+):** Lógica do jogo, detecção de colisões AABB, física simples (gravidade e impulso de salto) e gestão de estados (*Start, Playing, Game Over*).
* **CSS3 Minimalista:** Layout limpo e responsivo adaptado para PC e dispositivos móveis.
